# Dark Files

Файловый менеджер для Android (Kotlin + Jetpack Compose), тёмная тема в стиле Google Files.

## Способы запуска
- **Shizuku** — доступ к `Android/data` и `Android/obb` через Shizuku (shell или root).
- **ADB (через ПК)** — вкладка «Запуск» → «Создать скрипт», затем на ПК: `adb shell sh <путь к start.sh>`.
- **Без запуска** — доступа к файлам нет.

## Возможности
- Просмотр, копирование, перемещение, переименование, удаление, новая папка, поиск, сортировка.
- Вкладка «Приложения»: у каждого приложения адреса `Android/data`, `Android/obb`, `Android/media`,
  `/data/data/...` и `databases` (последние два — только с root). Любой адрес можно добавить в быстрый доступ.
- Встроенный видеоплеер (Media3): файлы читаются через Shizuku/ADB, поэтому видео из `Android/data` тоже играют.
- Настройки: тема, скрытые файлы, сортировка, подтверждение удаления, порт ADB, автоподключение, автозапуск видео, свои адреса.

## Сборка на GitHub
1. Загрузите содержимое папки в репозиторий (ветка `main`).
2. Вкладка **Actions** → **Build APK** → запустится сам (или «Run workflow»).
3. Готовый `app-debug.apk` лежит в артефакте **DarkFiles-debug-apk**.
