# KoFiles

Файловый менеджер для Android на Kotlin и Jetpack Compose: тёмная тема и синий акцент в стиле Google Files,
доступ к `Android/data` и `Android/obb` через Shizuku или ADB.

> **Название.** KoFiles — это бывший **Dark Files** (в разговорах и старых архивах — **darkfile**).
> Проект тот же, переименованы приложение, пакет (`com.example.kofiles`) и тема.
> Если у вас установлен Dark Files, KoFiles встанет как отдельное приложение — старое можно удалить.

## Способы запуска
| Способ | Что даёт |
|---|---|
| **Shizuku** | Полный доступ к файлам Android (shell или root, в зависимости от того, как запущен Shizuku). Подойдёт и форк Shizuku. |
| **ADB (через ПК)** | Вкладка «Запуск» → «Создать скрипт», затем на ПК: `adb shell sh <путь к start.sh>`. Права shell, root не нужен. |
| **Без запуска** | Доступа к файлам нет, работает только просмотр списка приложений. |

После обновления с версии Dark Files / KoFiles 1.0 перезапустите ADB-сервер на телефоне
(«Остановить сервер на телефоне» → снова команда с ПК): протокол обмена изменился.

## Что умеет
- Просмотр папок, копирование, перемещение, переименование, удаление, новая папка, поиск, сортировка, скрытые файлы.
- **Нажатие на файл** — KoFiles проверяет, какие приложения на устройстве умеют открывать файл такого типа, и показывает список:
  встроенные просмотрщики, совместимые приложения, «Поделиться». Для файлов из `Android/data` делается временная копия.
  Отключается в настройках («Спрашивать, чем открыть файл») — тогда встроенный просмотр открывается сразу.
- **Изображения** — листание фото из папки, увеличение двумя пальцами и двойным касанием, поворот по EXIF.
- **Музыка** — плейлист из треков папки, обложка, название и исполнитель из тегов, перемотка.
- **Видео** — встроенный плеер (Media3), файлы читаются напрямую, в том числе из `Android/data`.
- **Архивы** — zip, jar, apk, xapk, apks, apkm, cbz, 7z, tar, tar.gz/tgz, tar.bz2, tar.xz, gz, bz2, xz:
  просмотр содержимого, открытие файла из архива, распаковка всего или выбранного в папку рядом с архивом
  (через Shizuku/ADB, поэтому работает и в `Android/data`). Русские имена в старых zip (CP866) читаются корректно.
  RAR и архивы с паролем не поддерживаются — откройте их в стороннем приложении.
- **APK** — на выбор:
  1. обычный системный установщик;
  2. кастомные установщики, если они есть на устройстве (SAI, InstallerX и подобные);
  3. установка силами KoFiles через Shizuku/ADB (`pm install`, без системного окна).
  Для обычного установщика нужно один раз разрешить KoFiles установку приложений.
- Вкладка «Приложения»: адреса `Android/data`, `Android/obb`, `Android/media`, `/data/data/...` и `databases`
  (последние два — только с root), любой адрес добавляется в быстрый доступ.
- Настройки: тема, скрытые файлы, сортировка, подтверждение удаления, порт ADB, автоподключение,
  автозапуск видео, свои адреса, очистка временных файлов.

## Сборка на GitHub
1. Загрузите содержимое папки в репозиторий (ветка `main`).
2. Вкладка **Actions** → **Build APK** запустится сама (или «Run workflow»).
3. Готовый `app-debug.apk` лежит в артефакте **KoFiles-debug-apk**.

## Структура
- `server/` — код, который работает внутри процесса shell/root: `FileOps` (файловые операции, запись, `pm install`),
  `FileService` (Shizuku), `AdbServer` (ADB).
- `data/` — транспорты, `RemoteFs`, архивы (`Archives`), загрузка изображений, проверка совместимости (`Opener`), настройки.
- `ui/` — экраны: файлы, приложения, запуск, настройки, окно «чем открыть», просмотр изображений, музыки, видео и архивов.
